让 AI agent 自己做研究

给 AI 一份小而真实的 LLM 训练代码，让它修改代码 → 训练 5 分钟 → 看结果 → 保留或丢弃， 不停迭代。你睡觉时它在跑实验，醒来就能看到一份「实验日志」与（也许）一个更好的模型。

~12/h
每小时实验数
1 file
agent 只改这一个

1核心思想

固定时间预算 + 单一指标

每次实验都跑 正好 5 分钟，然后报告 val_bpb（验证集上每字节的比特数，越低越好）。 因为时间固定，无论 agent 怎么改架构、改优化器、改 batch size，结果都是公平可比的。

「只改一个文件」

agent 只修改 train.py。prepare.py 与评估流程是只读的——这就保证了它没法「作弊」（比如改评估指标）。
